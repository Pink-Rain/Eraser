# Eraser 0.1.1-alpha.143 — Index du vocabulaire sur le moteur des index

Cette version arrive par la mise à jour sans réinstallation.

## Nouvel index : Vocabulaire

- **Index › Vocabulaire** : la feuille « Vocabulaire » déjà présente dans le Drive, branchée
  sur le moteur des index. Aucune feuille créée, aucune colonne ajoutée : ce sont les mêmes
  lignes que la page **Règles › Vocabulaire**, qui continue de les lire.
- Tout le moteur s'y applique : tableau, fiche d'une ligne (enregistrement automatique,
  Précédente / Aller à… / Suivante), ajout d'un mot directement dans le tableau, recherche,
  tri, filtres, onglets-fenêtres, « Modifier », mise en page de la fiche et du survol, presets.
- La définition garde sa mise en forme (paragraphes, listes, gras…) : l'index la lit et la
  réécrit exactement comme la page Vocabulaire. Une modification faite d'un côté se voit de
  l'autre.
- Liens croisés : « Voir la page Vocabulaire » depuis l'index, « Ouvrir l'index du
  vocabulaire » depuis la page (MJ et administrateurs).
