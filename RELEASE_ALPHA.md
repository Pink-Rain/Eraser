# Eraser 0.1.1-alpha.274 — Les extensions se mettent à jour d'un clic

Cette version arrive **sans réinstallation** (même enveloppe que l'alpha 273) : Eraser la
télécharge, redémarre son serveur et recharge la page tout seul. Rien ne change dans Google Sheets.

- **« Chercher les mises à jour » vérifie aussi les extensions** : le bouton du bas de la barre
  latérale cherche une nouvelle version d'Eraser et, en même temps, des extensions que le compte
  reçoit (joueurs compris). Une nouvelle version est installée tout de suite, et le message sous le
  bouton le dit : « Eraser Map est passée à 0.2.0 », ou « Aucune mise à jour ».
- **Une extension mise à jour toute seule est annoncée** : quand une extension s'est mise à jour en
  arrière-plan (au lancement d'Eraser ou dans les heures qui suivent), le même message apparaît
  sous le bouton à la page suivante, une seule fois.
- Rouvrir une extension déjà affichée (ou actualiser avec F5) pour profiter de sa nouvelle version.
