# Eraser 0.1.1-alpha.298 — Compagnon Roll20 : plus simple

Sans réinstallation (même enveloppe que l'alpha 297). Rien ne change dans Google Sheets.

Dossier de campagne › **Compagnon Roll20** :

1. **Mettre à jour le compagnon** : un bouton.
2. **Recharger** : `chrome://extensions` ou `opera://extensions` (bouton **Copier**), puis **↻** sur
   **Eraser**. L'étape se coche toute seule.
3. **Copier le script** → **Ouvrir les scripts Roll20** → Ctrl+A, Ctrl+V, **Save Script**.

- Les boutons « Ouvrir dans Chrome / Opera » disparaissent : ces navigateurs refusent d'être ouverts
  sur leur page des extensions par un autre programme.
- Le compagnon (0.10.1) dit à Eraser sa version et celle du script Mod : les étapes déjà faites se
  cochent seules.
- Un correctif du compagnon seul ne demande plus de recoller le script Mod (même famille 0.10).
- Le panneau Roll20 perd ses longs textes.
