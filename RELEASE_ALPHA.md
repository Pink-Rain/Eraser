# Eraser 0.1.1-alpha.163 — Le fil d'Ariane façon explorateur

Cette version arrive par la mise à jour sans réinstallation.

## La barre du haut, comme l'explorateur de Windows

- **Chaque étape est cliquable.** Une étape qui est une page l'ouvre ; une étape qui n'est
  qu'un dossier (« Personnages », « Règles », « Campagnes ») ouvre la liste de ce qu'elle
  contient.
- **Chaque « › » ouvre le contenu** de l'étape à sa gauche, la page actuelle en évidence.
  Celui d'« Eraser » montre les grandes sections, chacune avec son sous-menu (Index → tous
  les index, avec « Ouvrir Index » en tête).
- Seul ce à quoi le compte a accès est proposé : un joueur y trouve ses personnages, ses
  campagnes et les règles.
- La flèche de retour de la barre est retirée (elle existe déjà ailleurs).
