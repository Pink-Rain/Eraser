# Eraser 0.1.1-alpha.296 — Le compagnon Roll20 en trois clics

Cette version arrive **sans réinstallation** (même enveloppe que l'alpha 295) : Eraser la
télécharge, redémarre son serveur et recharge la page tout seul. Rien ne change dans Google Sheets.

Dans le **dossier de la campagne › Compagnon Roll20**, la mise à jour se fait maintenant en trois
étapes, un bouton chacune, sans rien télécharger :

1. **Mettre à jour les fichiers sur ce PC** : Eraser range lui-même le compagnon dans son dossier.
   « Choisir son dossier… » retrouve celui déjà chargé dans le navigateur (une seule fois) ; sinon il
   est rangé dans Documents\Eraser\Compagnon Roll20.
2. **Recharger le compagnon dans le navigateur** : « Ouvrir dans Chrome » ou « Ouvrir dans Opera »
   ouvre directement la page des extensions ; il reste à cliquer sur ↻ sous le compagnon. La première
   fois, l'étape explique comment l'ajouter. Dès cette version, le compagnon se recharge aussi tout
   seul à l'ouverture de Roll20 quand Eraser a mis son dossier à jour.
3. **Mettre à jour le script Mod** : « Copier le script », puis « Ouvrir la page des scripts Roll20 »
   (lien déduit de celui de la partie, ou réglé par le MJ), Ctrl+A, Ctrl+V, « Save Script ».

- Plus de fenêtre bloquée sur le texte du script : Eraser ne l'ouvre plus, il le copie.
- Compagnon et script Mod en **0.10.0** (à faire une fois avec les trois étapes).
