# Eraser 0.1.1-alpha.206 — Toutes les vues dans les pages, réglables sur place

Cette version arrive par la mise à jour sans réinstallation. Rien n'est écrit dans Google
Sheets.

## Bloc « Vue d'index » d'une page

- **Toutes les présentations sont proposées** : tableau, cartes, liste, kanban,
  maître-détail, calendrier, tableau de bord, galerie, chronologie, arborescence, codex.
  Avant, seules celles déjà réglées dans « Modifier › Vues » de l'index apparaissaient (un
  point les signale toujours).
- **Les vues enregistrées de l'index** (onglets-fenêtres) se choisissent dans le bloc : seules
  leurs lignes s'affichent, dans leur présentation.
- **« Forme : propre à cette page »** : la présentation se règle directement dans le bloc
  (colonnes, regroupement, carte de chaque élément, apparence…), sans toucher à l'index. Elle
  part de la forme de l'index s'il y en a une ; « Celle de l'index » revient en arrière.
- Les colonnes cachées aux joueurs restent cachées, quelle que soit la forme choisie.
