# Eraser 0.1.1-alpha.145 — « { » : chaque index se cite aussi par son propre nom

Cette version arrive par la mise à jour sans réinstallation.

## Citer une ligne avec « { »

- Le menu « { » proposait chaque index sous le mot de ses lignes seulement (« un mot » →
  « Mot », « une créature » → « Créature ») : `{vocabulaire:` ne trouvait rien. **Chaque
  index se cite maintenant aussi par son nom** (`{Vocabulaire:Entité}`, `{Bestiaire:…}`),
  et chaque onglet par son nom en plus du mot de ses lignes.
- C'est le moteur des index qui le fait : tout index, prévu par Eraser ou créé dans
  « Nouvel index », en profite sans rien régler.

Rappel de la 144 : le vocabulaire est un index du moteur à part entière (colonne « Nom »
officielle, « ID » masqué), les mêmes lignes que la page Règles › Vocabulaire.
